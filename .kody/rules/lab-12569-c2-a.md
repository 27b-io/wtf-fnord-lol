## Instructions
Scratch-only fixture for the LAB-12569 rename-edge trial (c2-a). Flag any JSON.parse of external input in scratch fixtures that is not wrapped in error handling.

## Examples

### Bad example
```ts
const cfg = JSON.parse(raw);
```

### Good example
```ts
let cfg;
try { cfg = JSON.parse(raw); } catch (e) { throw new Error(`bad config: ${e}`); }
```
