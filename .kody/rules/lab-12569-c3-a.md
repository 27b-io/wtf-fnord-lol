## Instructions
Scratch-only fixture for the LAB-12569 rename-edge trial (c3-a). Flag any setInterval in scratch fixtures whose handle is never cleared, since it keeps the process alive.

## Examples

### Bad example
```ts
setInterval(poll, 1000);
```

### Good example
```ts
const h = setInterval(poll, 1000);
process.on('SIGTERM', () => clearInterval(h));
```
